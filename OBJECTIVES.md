# RTL objectives

- Develop dependable arithmetic, execution-control and memory blocks for the agreed workloads.
- Keep interface, timing, numerical and reset assumptions explicit across blocks.
- Preserve reproducible design evidence and independently assess correctness.

Area-specific objectives: [Compute](docs/compute/OBJECTIVES.md),
[Control](docs/control/OBJECTIVES.md), [Memory](docs/memory/OBJECTIVES.md).
