# 32-bit SIMD signature catalogue

The SIMD ISA has 135 legal signatures, grouped below by `FAMILY`.

**Source: [Google Sheet — Signatures tab](https://docs.google.com/spreadsheets/d/1XtrQoqvEHGf_vmuHE5VzVlQ5l0E2RK3TIvoId99a1Kk/edit#gid=2).**

See the [ISA specification](simd-isa.md) for the word layout, register references,
masking, scalar execution, and fault rules. `SUM` includes every physical lane;
inactive and masked lanes contribute zero.

In the tables, `V/S/K` means vector, scalar, or constant. Predicate roles select
`P` registers. Unused fields are zero, and `CONTROL` requires `PM=0`.
