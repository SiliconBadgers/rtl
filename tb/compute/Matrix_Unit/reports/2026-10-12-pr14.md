## What the counts mean

- `shadow_path_checks` / `active_path_checks`: (a, b) pairs checked with the PE
  reading its shadow register (switch cycle) or its active register (no switch).
  Every one of the 65,536 int8 pairs is checked once on each path; the other
  register holds ~a, so reading the wrong register fails.
- `reset_checks`: swap_o checks during reset and after release.
- `columns_sent`: B columns driven, each predicting one C column.
- `columns_checked`: C columns compared with the model (all Rows values, the
  order, and the latency of exactly Rows + Cols + 1 cycles).
- `cancelled`: columns in flight when reset was asserted; reset discards them, so
  `columns_checked = columns_sent - cancelled` is required.
- `rows_accepted`: A rows transferred. `a_stalls`: cycles a valid A row waited for
  a_ready (zero for 1x1, which never stalls). `switches`: tile switches.
- `cycles`: falling-edge steps in the run. Elapsed is wall-clock seconds for the
  run, excluding compilation.

## Not checked, and limitations

- Gate-level simulation, synthesis, timing, and CDC/reset-structure checks.
- Four-state (X) behaviour beyond what Icarus shows; Verilator is two-state.
- The int4 mode is not implemented; only its error flag is checked.
- The ALL_CAPS localparams carry a scoped Verible `parameter-name-style` waiver;
  see the PR discussion.
